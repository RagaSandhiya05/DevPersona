# 💚 DevPersona

### Your Developer Identity, Right Inside the Terminal.

DevPersona is a lightweight, personalized Python terminal experience that displays a developer profile with animated text, green-themed terminal styling, random greetings, and motivational coding quotes.

Instead of a traditional profile page, DevPersona brings your developer identity directly to the command line.

---

> <i>💭 **A different kind of GitHub addition**
>
> I've been building AI applications and working on larger projects, so I wanted to try something on a smaller scale this time. DevPersona started as a simple idea: what if a terminal could introduce the developer behind it? Just a little Python, a personalized profile, and a green terminal aesthetic. 💚</i>

---

## ✨ Features

- **Personalized Developer Profile** – Displays your name, role, education, interests, and programming languages.
- **Green Terminal Theme** – A consistent green aesthetic using Colorama.
- **Typing Animation** – Displays messages with a typewriter effect.
- **Random Greetings** – Shows a different welcome message on each execution.
- **Random Developer Quotes** – Displays motivational programming quotes.
- **Lightweight & Simple** – Built entirely with Python and minimal dependencies.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/RagaSandhiya05/DevPersona.git
```

### 2. Navigate to the Directory

```bash
cd DevPersona
```

### 3. Create a Virtual Environment

```bash
python -m venv .venv
```

### 4. Activate the Virtual Environment

**Windows:**

```powershell
.venv\Scripts\activate
```

**Linux / macOS:**

```bash
source .venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run DevPersona

```bash
python main.py
```

That's it! Your personalized developer profile will appear in the terminal. 💚

---

## 🎨 Customization

DevPersona can be personalized by modifying the developer information in `main.py`.

You can customize:

- **Name:** Your preferred display name.
- **Role:** Your current developer role or career aspiration.
- **Education:** Your academic background.
- **Interests:** Your technical interests.
- **Languages:** Your programming languages.

You can also add your own greetings and motivational quotes to the predefined lists.
